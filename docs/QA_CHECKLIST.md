# Darbak Release QA Checklist

لا يعتمد أي APK نهائي قبل اجتياز هذه القائمة.

## Build / Version
- [ ] package name صحيح ولم يتغير دون قرار مقصود.
- [ ] versionCode أعلى من الإصدار السابق.
- [ ] versionName مطابق لسجل الإصدار.
- [ ] Release APK مبني بالتوقيع الصحيح.
- [ ] لا يوجد أكثر من APK نهائي لنفس versionCode.

## Android 7.1 / 1024×600
- [ ] تثبيت نظيف على API 25.
- [ ] تحديث فوق النسخة السابقة دون فقد البيانات.
- [ ] التشغيل أفقي 1024×600 دون قص عناصر.
- [ ] RTL صحيح.
- [ ] النص قابل للقراءة من مسافة السيارة.
- [ ] عناصر اللمس كبيرة ولا تتداخل.

## Startup / Long use
- [ ] فتح وإغلاق التطبيق 20 مرة دون crash.
- [ ] الرجوع للخلف من كل شاشة دون crash.
- [ ] الانتقال للخلفية والعودة 10 مرات.
- [ ] تشغيل ممتد لا يقل عن 30 دقيقة للوظائف المستمرة.
- [ ] لا يوجد تسرب واضح في الذاكرة أو نمو مستمر غير مبرر.

## Failure paths
- [ ] رفض كل صلاحية لا يسبب crash.
- [ ] عدم وجود إنترنت يعرض حالة واضحة.
- [ ] ملف مفقود/تالف يعرض حالة واضحة.
- [ ] مساحة تخزين منخفضة تعالج بوضوح.
- [ ] انقطاع الشبكة أثناء التنزيل لا يثبت APK جزئي.
- [ ] SHA-256 غير مطابق يوقف التثبيت.

## Data / Migration
- [ ] بيانات النسخة السابقة مقروءة بعد التحديث.
- [ ] أي تغيير Schema له migration واختبار رجوعي.
- [ ] إعدادات المستخدم المهمة لا تعود للوضع الافتراضي بلا سبب.
- [ ] النسخة الاحتياطية/الاستعادة تعمل إذا كان التطبيق يستخدمها.

## Darbak Identity
- [ ] الإعدادات تستخدم Darbak Settings UI V1.
- [ ] صفحة حول موجودة.
- [ ] «دربك — تصميم وتطوير — أبوسلطان» موجود دون تعديل.
- [ ] الضغط المطول على الإصدار يفتح التشخيص.
- [ ] حالات Loading/Error/Empty/Permission/Storage متسقة.

## Update
- [ ] فحص التحديث يعمل.
- [ ] الإصدار الحالي لا يقترح نفسه كتحديث.
- [ ] changelog صحيح.
- [ ] APK النهائي له SHA-256 منشور في manifest.
- [ ] التثبيت فوق النسخة السابقة ينجح بالتوقيع نفسه.

## Final gate
- [ ] Darbak Diagnostics = HEALTHY أو تم توثيق سبب الاستثناء.
- [ ] لا توجد مشكلة معروفة تسبب crash/ANR أو فقد بيانات.
- [ ] تمت تجربة APK على شاشة السيارة الفعلية قبل وصفه بأنه «مكتمل».
