# Darbak Platform — Production Release Standard

آخر تحديث: 2026-09-08

هذا المعيار إلزامي لكل تطبيقات دربك الحالية والقادمة. نجاح Build أو دمج Darbak Platform لا يعني أن APK أصبح Production.

## بوابات الإصدار

1. **Version Gate**
   - `versionCode` أعلى من آخر إصدار موزع.
   - `versionName` بصيغة واضحة ومتسقة.
   - لا توجد نسختان نهائيتان بنفس `versionCode`.

2. **Signing Gate**
   - كل APK Production يجب أن يوقّع بمفتاح ثابت معروف لذلك التطبيق.
   - مفاتيح التوقيع غير الموجودة أصلًا في المستودع تحفظ في Google Drive الخاص `Darbak Signing Keys` ولا تنشر داخل GitHub.
   - إذا تغيّر مفتاح تطبيق كان مثبتًا سابقًا بتوقيع Debug/مختلف، يلزم تثبيت Production يدويًا مرة واحدة؛ بعد ذلك تمنع المنصة أي APK بتوقيع مختلف.

3. **Update Integrity Gate**
   - HTTPS فقط.
   - `versionCode` أعلى من النسخة الحالية.
   - package name مطابق.
   - SHA-256 مطابق.
   - minimum SDK متوافق مع الجهاز.
   - شهادة APK مطابقة للنسخة المثبتة.
   - لا يبدأ التثبيت إذا فشل أي فحص.

4. **CI Gate**
   - اختبارات التطبيق الخاصة به.
   - Build ناجح.
   - Lint ناجح حيثما كان مفعّلًا.
   - اختبارات Android 7/API25 أو Robolectric/Emulator عندما تكون متاحة.
   - لا دمج لفرع Production hardening قبل نجاح البوابة.

5. **Distribution Gate**
   - المستودعات يمكن أن تبقى Private.
   - ملفات التحديث العامة فقط (manifest/APK) توضع في قناة توزيع Drive العامة المخصصة.
   - لا يُستخدم رابط GitHub Private كـ update feed على شاشة السيارة.
   - الملف الموجود في قناة التوزيع يجب أن يكون Release معتمدًا، لا Debug artifact.

6. **Physical Head-Unit Gate**
   - Android 7.1/API25 على شاشة السيارة الفعلية.
   - 1024×600 landscape.
   - فتح/إغلاق/رجوع وتشغيل طويل.
   - صلاحيات وتخزين منخفض واتصال منقطع.
   - تحديث فوق النسخة السابقة وإعادة تشغيل الشاشة.
   - التطبيقات المترابطة تختبر معًا على ذاكرة الجهاز الحقيقية.

## تسمية ملفات Production

`<AppName>-<versionName>-<versionCode>-production.apk`

لا يوضع `debug`, `test`, `qa` أو رقم تشغيل CI في اسم النسخة التي ستصل للمستخدم.

## الهوية

كل إصدار يلتزم بهوية:

`دربك — تصميم وتطوير — أبوسلطان`

ويطبق Darbak Settings UI V1 وصفحة حول والتشخيص المحلي ومعايير الحالات المشتركة عندما تكون ذات صلة بالتطبيق.

## قاعدة ذهبية

لا يتم تجاوز أي Gate بهدف تسريع التسليم. إذا كان التحديث المتخصص في تطبيق قائم أقوى من Darbak Core العام، يُحافظ عليه ويُربط بمعايير الأمان بدل استبداله.
