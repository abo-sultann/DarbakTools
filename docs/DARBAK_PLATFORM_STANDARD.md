# Darbak App Platform — Standard V1

هذا المستند هو المرجع الملزم لجميع تطبيقات دربك الحالية والقادمة.

## 1. الهدف
- شاشة السيارة الأساسية: Android 7.1 / API 25.
- الدقة المرجعية: 1024×600 أفقي.
- اللغة: العربية RTL.
- الأولوية: الاستقرار ثم الأداء ثم سهولة الاستخدام ثم المؤثرات البصرية.
- لا تعتمد ميزة أساسية على Play Store أو Firebase.

## 2. الهوية المعتمدة
- الاسم البصري: Darbak Settings UI V1.
- خلفية ليلية داكنة هادئة.
- بطاقات زجاجية خفيفة بحد أزرق رفيع وزوايا كبيرة.
- اللون الأساسي: أزرق Darbak.
- الحالات: أخضر = سليم/متصل، أصفر = تنبيه، أحمر = مشكلة.
- الذهبي يستخدم للهوية والملكية فقط.
- عناصر لمس كبيرة، نص عربي واضح، وتقليل الشرح غير الضروري.

## 3. الملكية وصفحة حول
كل تطبيق يجب أن يحتوي صفحة «حول» موحدة تعرض:
- اسم التطبيق.
- الإصدار الحالي.
- منصة Android.
- التحقق من التحديث عند توفر مصدر تحديث.
- هوية الملكية المعتمدة دون تعديل: «دربك — تصميم وتطوير — أبوسلطان».
- الضغط المطول على بطاقة الإصدار يفتح شاشة الصيانة والتشخيص المخفية.

## 4. Darbak Core
أي تطبيق يتم تحديثه بعد اعتماد هذه الوثيقة يجب أن يضيف ما يناسبه من Core:
- DarbakCore: تهيئة الشاشة والتقاط الانهيارات.
- DarbakUi: مكونات التصميم المشتركة.
- DarbakAboutActivity: صفحة حول.
- DarbakDiagnostics: فحص الموارد وتقرير فني.
- DarbakDiagnosticsActivity: وضع الخدمة المخفي.
- DarbakUpdater: فحص/تنزيل/التحقق SHA-256/تثبيت تحديث APK.
- DarbakBackup: نسخة احتياطية لإعدادات SharedPreferences.
- DarbakStateView: حالات التحميل والنجاح والخطأ والصلاحيات والتخزين.
- DarbakSplashActivity: شاشة بداية خفيفة اختيارية.

## 5. التحديثات
صيغة manifest القياسية:
```json
{
  "versionCode": 10002,
  "versionName": "1.0.2",
  "apkUrl": "https://.../app.apk",
  "sha256": "<64 hex chars>",
  "notes": "ما الجديد"
}
```
القواعد:
- لا تثبيت قبل اكتمال التنزيل.
- SHA-256 إلزامي في الإصدارات النهائية.
- لا يتم حذف بيانات المستخدم أثناء تحديث عادي.
- النسخة الجديدة يجب أن تقرأ بيانات النسخة السابقة أو تنفذ migration صريحًا.

## 6. الإصدارات
- versionName = Major.Minor.Patch.
- versionCode تصاعدي ولا يعاد استخدامه.
- Major: تغيير غير متوافق أو إعادة بناء كبيرة.
- Minor: ميزة جديدة متوافقة.
- Patch: إصلاح أو تحسين محدود.
- لا يوجد أكثر من APK نهائي معتمد لنفس versionCode.

## 7. الصلاحيات
- أقل عدد ممكن من الصلاحيات.
- لا تطلب صلاحية قبل الحاجة إليها.
- كل رفض للصلاحية يعرض حالة Darbak موحدة ولا يسبب crash.
- الصلاحيات التي لا تخدم وظيفة فعلية تُحذف.

## 8. بدء التشغيل والاستقرار
- DarbakCore.install() يبدأ مبكرًا.
- لا Network/IO ثقيل على Main Thread.
- الوظائف غير الحرجة لا تمنع فتح التطبيق.
- كل قراءة ملف/شبكة/قاعدة بيانات لها مسار خطأ واضح.
- تجنب مؤثرات Blur/Animation الثقيلة على شاشة 1GB RAM.

## 9. حالات الواجهة القياسية
كل تطبيق يستخدم حالات موحدة عند الحاجة:
- Loading.
- Success.
- Empty.
- Error.
- Permission required.
- Low storage.
ولا تظهر شاشة فارغة أو Dialog نظام غير مفهوم للمستخدم إذا كان بالإمكان تقديم حالة Darbak واضحة.

## 10. النسخ الاحتياطي
- إعدادات المستخدم المهمة يجب أن تكون قابلة للاستعادة عند التحديثات الكبيرة.
- DarbakBackup يغطي SharedPreferences.
- قواعد البيانات والملفات تحتاج migration/backup خاص بالتطبيق.

## 11. التشخيص
- فحص: الإصدار، Android، التخزين، heap المتاح، وآخر crash.
- تقرير التشخيص يحفظ محليًا فقط ما لم يطلب المستخدم مشاركته.
- وضع الخدمة غير ظاهر للمستخدم العادي.

## 12. معيار التسليم
لا يعتبر الإصدار مكتملاً حتى يجتاز QA_CHECKLIST.md.

## 13. قاعدة ثابتة
أي تطوير جديد يُنفذ وفق هذه المنظومة تلقائيًا. لا يتم تغيير الهوية أو توقيع «أبوسلطان» إلا بطلب صريح من المالك.
