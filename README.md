# DarbakTools

أدوات شاشة السيارة الخاصة بأبوسلطان.

## الهدف
تطبيق Android خفيف ومخصص لشاشة 1024×600 يعمل على Android 7.1 / API 25 بدون الاعتماد على متجر Google Play.

## النسخة الأولى
- مدير ملفات محلي.
- نقل الملفات بين iPhone والشاشة عبر الشبكة المحلية.
- صفحة اتصال محلية مناسبة لـ Safari.
- إرسال الروابط من iPhone إلى الشاشة.
- مركز تنزيلات.
- مركز APK للفحص والتثبيت.

## البناء
يتم بناء APK تلقائيًا عبر GitHub Actions عند كل push إلى `main`.
