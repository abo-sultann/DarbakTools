# DarbakTools — دربك Tools

صندوق أدوات خاص لشاشة السيارة، مصمم للعمل بخفة واستقرار على Android 7.1 / API 25 وشاشة 1024×600 أفقية.

## السيناريو الأساسي

الهدف أن يستطيع المستخدم تشغيل السيارة وترك الشاشة داخل السيارة، ثم الجلوس داخل المنزل وفتح DarbakTools من Safari على الآيفون والتحكم بالشاشة عن بُعد كأنه جالس أمامها، بشرط أن تكون الشاشة والآيفون على نفس الشبكة المحلية أو توجد بينهما شبكة يمكن الوصول عبرها محليًا.

## النسخة الأولى المعتمدة

1. مدير ملفات: الذاكرة الداخلية / USB / SD مع نسخ ونقل وحذف وإعادة تسمية وبحث وفرز.
2. اتصال الآيفون عبر الشبكة المحلية: صفحة محلية بدون الحاجة لتطبيق إضافي على الآيفون.
3. إرسال واستقبال الملفات بين الآيفون والشاشة.
4. إرسال الروابط من الآيفون إلى الشاشة وفتحها أو تنزيل الملفات المباشرة.
5. مركز تنزيلات مع اختيار مكان الحفظ ومتابعة التقدم وإعادة المحاولة.
6. مركز APK: عرض معلومات الحزمة والإصدار وفحص التوافق الأساسي ثم التثبيت بموافقة المستخدم.
7. التحكم الكامل بالشاشة من الآيفون عبر نفس صفحة الاتصال المحلية.

## التحكم بالشاشة من الآيفون

الهدف أن يتحول Safari على الآيفون إلى ريموت كامل للشاشة:

- عرض صورة الشاشة مباشرة على الآيفون بجودة ومعدل تحديث مناسبين لقدرات الجهاز.
- لمس مفرد في أي مكان مع تحويل إحداثيات الآيفون إلى إحداثيات شاشة 1024×600.
- السحب والتمرير في جميع الاتجاهات.
- الضغط المطول.
- أزرار رجوع / الرئيسية / التطبيقات الأخيرة عندما تسمح صلاحيات Android بذلك.
- كتابة نص من لوحة مفاتيح الآيفون إلى الحقل النشط في الشاشة عندما يكون ذلك ممكنًا.
- التحكم بمستوى الصوت: رفع / خفض / كتم.
- تشغيل التطبيقات المثبتة من صفحة الآيفون.
- إعادة الاتصال تلقائيًا عند انقطاع الشبكة ثم عودتها.
- وضع مشاهدة فقط عند الحاجة.

## تشغيل التحكم تلقائيًا

- لا يوجد رمز جلسة أو PIN.
- لا يطلب التطبيق إدخال رمز عند كل اتصال.
- خادم DarbakTools المحلي يبدأ تلقائيًا بعد إقلاع شاشة السيارة بواسطة Boot Receiver.
- عند اتصال الشاشة بالشبكة يصبح رابط التحكم متاحًا مباشرة من الآيفون.
- تحفظ إعدادات الشبكة والمنفذ محليًا.
- يمكن عرض عنوان ثابت داخل التطبيق مثل: `http://IP-OF-CAR:8080` مع إمكانية إضافة اختصار له على شاشة الآيفون الرئيسية.
- الخدمة مخصصة للشبكة المحلية فقط ولا تعتمد على سحابة أو خادم خارجي.

### ملاحظة أمان

إلغاء PIN يعني أن أي جهاز يستطيع الوصول إلى عنوان DarbakTools داخل نفس الشبكة قد يستطيع فتح صفحة التحكم. لذلك سيقتصر الاستماع افتراضيًا على الشبكة المحلية، مع خيار لاحق لتقييد الوصول إلى عنوان IP موثوق بدون إظهار رمز أو طلب تسجيل دخول للمستخدم.

## المتطلبات التقنية للتحكم

### الوضع العادي — بدون روت

- AccessibilityService لتنفيذ اللمس والسحب والأوامر العامة.
- `dispatchGesture()` متاح من API 24، وبالتالي مناسب لـ Android 7.1.
- خدمة Accessibility يتم تفعيلها يدويًا مرة واحدة من إعدادات Android ثم تبقى مفعلة ما لم يعطلها النظام أو المستخدم.
- MediaProjection لالتقاط صورة الشاشة وبثها للآيفون.
- Android يفرض موافقة المستخدم على جلسة MediaProjection؛ لذلك بعد إعادة تشغيل النظام قد يلزم تأكيد مشاركة الشاشة محليًا قبل أن يعمل العرض المباشر.
- بعد بدء جلسة الالتقاط يمكن إبقاؤها مستمرة طالما الخدمة والجهاز يعملان.

### الوضع المتقدم — تحكم كامل بدون الذهاب للسيارة

لتحقيق الهدف النهائي: تشغيل السيارة ثم التحكم من داخل المنزل بدون لمس شاشة السيارة بعد الإقلاع، سيتم دعم وضع متقدم إذا كانت الشاشة مروّتة أو أمكن تثبيت DarbakTools بصلاحيات نظام مناسبة.

في هذا الوضع نستهدف:

- بدء خدمة التحكم تلقائيًا مع الإقلاع.
- التقاط الشاشة بدون نافذة MediaProjection اليدوية باستخدام الصلاحيات المتقدمة المتاحة على الجهاز.
- تنفيذ أوامر اللمس والسحب وأزرار النظام تلقائيًا.
- عدم الحاجة إلى أي خطوة على شاشة السيارة بعد تشغيلها.

لن يكون الروت شرطًا لبقية خدمات DarbakTools؛ يستخدم فقط إذا احتجنا للوصول إلى التحكم التلقائي الكامل بعد الإقلاع.

## مبادئ المشروع

- Android 7.1 / minSdk 25.
- 1024×600 Landscape.
- العربية وRTL أولًا.
- Offline-first؛ نقل الملفات والتحكم المحلي لا يعتمدان على سحابة.
- لا Firebase ولا Google Services للوظائف الأساسية.
- واجهة خفيفة مناسبة لذاكرة محدودة.
- أزرار كبيرة مناسبة لشاشة السيارة.
- عدم تنفيذ عمليات حذف أو تثبيت حساسة دون تأكيد واضح.
- المشروع للاستخدام الخاص ويدعم تثبيت APK مباشرة خارج Google Play.
- Remote Server يعمل محليًا ويبدأ تلقائيًا بعد الإقلاع عند تفعيل خيار التشغيل التلقائي.

## المعمارية المبدئية

- تطبيق Android Native خفيف.
- وحدة File Manager.
- Local Transfer Server لخدمة صفحة الآيفون داخل الشبكة المحلية.
- Remote Control Server للتحكم المحلي بالشاشة.
- Boot Receiver لبدء الخدمات تلقائيًا بعد تشغيل الشاشة.
- Screen Capture: MediaProjection في الوضع العادي، ومسار متقدم عند توفر صلاحيات root/system.
- Remote Input باستخدام AccessibilityService، مع مسار shell/root اختياري عند توفره.
- Web Remote UI مهيأة لـ Safari على iPhone.
- Inbox موحد للملفات الواردة.
- Download Manager.
- APK Inspector / Installer.
- Settings للتخزين والشبكة ومجلدات الحفظ والتحكم عن بعد.

## مراحل التنفيذ

### المرحلة 1
هيكل Android الأساسي + واجهة رئيسية + مدير الملفات.

### المرحلة 2
خادم النقل المحلي + صفحة الآيفون + رفع وتنزيل الملفات.

### المرحلة 3

### المرحلة 4
مركز APK وفحص التوافق والتثبيت.

Boot Receiver + إعادة الاتصال التلقائي + تشغيل الخادم تلقائيًا عند تشغيل السيارة.

اختبار الوضع المتقدم root/system للوصول إلى تحكم كامل بعد الإقلاع بدون أي تدخل على شاشة السيارة.

### المرحلة 8
