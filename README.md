# DarbakTools — دربك Tools

تطبيق واحد خفيف لشاشة السيارة يجمع إدارة الملفات، نقل الملفات من وإلى الآيفون، التنزيلات، إدارة APK، والتحكم بالشاشة عن بُعد. مصمم خصيصًا لـ Android 7.1 / API 25 وشاشة 1024×600 أفقية.

## السيناريو الأساسي

تشغّل السيارة وتترك الشاشة تعمل، ثم تجلس في المنزل وتفتح DarbakTools من Safari على الآيفون. من نفس الصفحة تستطيع إدارة الملفات، إرسال واستقبال الملفات والروابط، تنزيل الملفات، وتشغيل الشاشة والتحكم بها كأنك جالس أمامها، متى كانت الشاشة والآيفون على شبكة يمكن الوصول بينهما محليًا.

## الوحدات النهائية بعد دمج الوظائف المتشابهة

### 1) مركز الآيفون — Darbak Web

صفحة محلية واحدة في Safari بدل خدمات منفصلة، وتشمل:

- الاتصال بالشاشة عبر عنوان محلي واحد.
- رفع ملفات من الآيفون إلى الشاشة.
- تنزيل ملفات من الشاشة إلى الآيفون.
- تصفح ملفات الشاشة المسموح بها من الآيفون.
- إرسال رابط إلى الشاشة لفتحه أو تنزيله.
- عرض شاشة السيارة مباشرة على الآيفون.
- لمس، سحب، تمرير، وضغط مطول على الشاشة من الآيفون.
- أزرار رجوع / الرئيسية / التطبيقات الأخيرة عندما يسمح النظام.
- الكتابة من لوحة مفاتيح الآيفون إلى الحقل النشط عندما يكون ذلك ممكنًا.
- رفع / خفض / كتم الصوت.
- تشغيل التطبيقات المثبتة من صفحة الآيفون.
- إعادة الاتصال تلقائيًا عند عودة الشبكة.
- وضع مشاهدة فقط عند الحاجة.

لا يوجد PIN أو رمز جلسة. الخدمة محلية ولا تعتمد على سحابة.

### 2) مركز الملفات والتنزيلات

تم دمج مدير الملفات والوارد والتنزيلات في وحدة واحدة:

- الذاكرة الداخلية / USB / SD.
- نسخ / نقل / حذف / إعادة تسمية.
- بحث وفرز حسب الاسم والحجم والتاريخ والنوع.
- مجلد وارد موحد لكل ما يصل من الآيفون.
- تنزيل ملفات من روابط مباشرة.
- اختيار مكان الحفظ.
- متابعة تقدم التنزيل وإعادة المحاولة.
- فتح الملفات بعد اكتمالها باستخدام التطبيق المناسب المتوفر على الشاشة.

### 3) مركز التطبيقات APK

تم تجميع كل وظائف ملفات التطبيقات في شاشة واحدة:

- اكتشاف ملفات APK الموجودة في الذاكرة أو USB أو SD أو الوارد.
- عرض اسم التطبيق والإصدار والحجم وPackage Name عندما تكون البيانات متاحة.
- فحص توافق أساسي مع Android 7.1 قبل محاولة التثبيت.
- تمييز APK العادي عن الحالات التي قد تحتاج Split APK أو طريقة مختلفة.
- تثبيت أو تحديث التطبيق بموافقة Android المطلوبة.
- الاحتفاظ بملفات APK المتوافقة التي يختارها المستخدم لاستخدامها لاحقًا.

### 4) مركز الاتصال والتحكم التلقائي

بدل وجود Local Transfer Server وRemote Control Server منفصلين، يستخدم المشروع خادمًا محليًا واحدًا يخدم Darbak Web بالكامل:

- يبدأ تلقائيًا بعد إقلاع الشاشة بواسطة Boot Receiver عند تفعيل التشغيل التلقائي.
- يستخدم عنوانًا ومنفذًا واحدًا لكل الخدمات.
- يحفظ إعدادات الشبكة والمنفذ محليًا.
- يعيد تهيئة الاتصال عند تغير الشبكة.
- يمكن إضافة عنوان DarbakTools إلى الشاشة الرئيسية في الآيفون كاختصار.

## التحكم بالشاشة — المتطلبات التقنية

### الوضع العادي بدون روت

- AccessibilityService لتنفيذ اللمس والسحب والأوامر العامة.
- `dispatchGesture()` متاح من API 24، لذلك يناسب Android 7.1.
- خدمة Accessibility تحتاج تفعيلًا يدويًا من إعدادات Android.
- MediaProjection لالتقاط الشاشة وعرضها على الآيفون.
- Android قد يطلب موافقة محلية على جلسة مشاركة الشاشة بعد إعادة التشغيل.

### الوضع المتقدم Root/System

هدفه تحقيق السيناريو النهائي: تشغيل السيارة ثم التحكم من المنزل بدون أي تدخل على الشاشة بعد الإقلاع.

عند توفر root أو صلاحيات نظام مناسبة نستهدف:

- بدء الالتقاط والتحكم تلقائيًا بعد الإقلاع.
- عدم الحاجة إلى نافذة MediaProjection اليدوية.
- تنفيذ أوامر النظام واللمس والسحب تلقائيًا.
- عدم الحاجة للذهاب إلى السيارة بعد تشغيلها.

الروت ليس شرطًا لبقية خدمات DarbakTools؛ يدرس فقط لتحقيق التحكم التلقائي الكامل بعد الإقلاع.

## مبادئ المشروع

- Android 7.1 / minSdk 25.
- 1024×600 Landscape.
- العربية وRTL أولًا.
- Android Native خفيف ومناسب لذاكرة محدودة.
- Offline-first؛ نقل الملفات والتحكم محليان.
- لا Firebase ولا Google Services للوظائف الأساسية.
- لا Google Play مطلوب؛ APK للتثبيت المباشر.
- خادم محلي واحد لكل خدمات الآيفون لتقليل استهلاك الذاكرة والتعقيد.
- عدم تكرار الوظائف في أكثر من شاشة أو خدمة.
- عمليات الحذف والتثبيت الحساسة تحتاج تأكيدًا واضحًا على الشاشة المناسبة.

## المعمارية المعتمدة

- Android App.
- Unified Local Server.
- Darbak Web UI لـ Safari على iPhone.
- File & Download Center.
- APK Center.
- Screen Capture.
- Remote Input.
- Boot Receiver.
- Settings.
