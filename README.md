# DarbakTools — دربك Tools

صندوق أدوات خاص لشاشة السيارة، مصمم للعمل بخفة واستقرار على Android 7.1 / API 25 وشاشة 1024×600 أفقية.

## النسخة الأولى المعتمدة

1. مدير ملفات: الذاكرة الداخلية / USB / SD مع نسخ ونقل وحذف وإعادة تسمية وبحث وفرز.
2. اتصال الآيفون عبر الشبكة المحلية: صفحة محلية + QR بدون الحاجة لتطبيق إضافي على الآيفون.
3. إرسال واستقبال الملفات بين الآيفون والشاشة.
4. إرسال الروابط من الآيفون إلى الشاشة وفتحها أو تنزيل الملفات المباشرة.
5. مركز تنزيلات مع اختيار مكان الحفظ ومتابعة التقدم وإعادة المحاولة.
6. مركز APK: عرض معلومات الحزمة والإصدار وفحص التوافق الأساسي ثم التثبيت بموافقة المستخدم.
7. التحكم بالشاشة من الآيفون عبر نفس صفحة الاتصال المحلية.

## التحكم بالشاشة من الآيفون

الهدف أن يتحول الآيفون إلى لوحة تحكم حقيقية للشاشة عند وجود الجهازين على نفس Wi‑Fi أو Hotspot.

- عرض صورة الشاشة مباشرة على الآيفون بجودة ومعدل تحديث مناسبين لقدرات الجهاز.
- تنفيذ لمس مفرد في المكان المقابل على الشاشة.
- السحب والتمرير في الاتجاهات المختلفة.
- ضغط مطول عند الحاجة.
- أزرار رجوع / الرئيسية / التطبيقات الأخيرة عندما تسمح صلاحيات Android بذلك.
- كتابة نص من لوحة مفاتيح الآيفون وإرساله إلى الحقل النشط في الشاشة عندما يكون ذلك ممكنًا.
- التحكم بمستوى الصوت: رفع / خفض / كتم.
- زر إعادة الاتصال وتوضيح حالة الاتصال الحالية.
- وضع مشاهدة فقط لتعطيل أوامر اللمس مؤقتًا.
- إنهاء جلسة التحكم من الشاشة أو الآيفون فورًا.

### المتطلبات التقنية للتحكم

- استخدام MediaProjection لالتقاط الشاشة بعد موافقة المستخدم المطلوبة من Android.
- استخدام AccessibilityService لتنفيذ اللمس والسحب والأوامر العامة المتاحة على Android 7.1 / API 25 بعد تفعيل خدمة إمكانية الوصول يدويًا من الإعدادات.
- بث محلي فقط داخل الشبكة؛ لا يتم رفع صورة الشاشة إلى الإنترنت أو السحابة.
- حماية جلسة التحكم برمز مؤقت / Session PIN يظهر على الشاشة.
- عدم قبول أوامر تحكم من أي جهاز جديد قبل المصادقة.
- إيقاف خدمة التحكم تلقائيًا عند إنهاء الجلسة أو فقد الاتصال حسب الإعدادات.

### حدود Android 7.1

- أول تشغيل لالتقاط الشاشة يتطلب موافقة نظام Android على مشاركة الشاشة، ولا يجوز افتراض تجاوزها بدون صلاحيات نظام/روت.
- خدمة Accessibility يجب تفعيلها يدويًا مرة واحدة من إعدادات إمكانية الوصول.
- بعض أوامر النظام قد تختلف حسب روم شاشة السيارة، لذلك سيتم توفير بدائل وعدم جعلها سببًا لتعطل التطبيق.
- لا نعتمد على الروت في النسخة الأساسية؛ يمكن دراسة وضع متقدم للروت لاحقًا إذا ثبتت الحاجة إليه على الشاشة نفسها.

## مبادئ المشروع

- Android 7.1 / minSdk 25.
- 1024×600 Landscape.
- العربية وRTL أولًا.
- Offline-first؛ نقل الملفات والتحكم المحلي لا يعتمدان على سحابة.
- لا Firebase ولا Google Services للوظائف الأساسية.
- واجهة خفيفة مناسبة لذاكرة محدودة.
- أزرار كبيرة مناسبة لشاشة السيارة.
- عدم تنفيذ عمليات حذف أو تثبيت حساسة دون تأكيد واضح.
- المشروع للاستخدام الخاص ويدعم تثبيت APK مباشرة خارج Google Play.
- خدمات التحكم عن بعد مغلقة افتراضيًا ولا تبدأ إلا بإجراء واضح من المستخدم.

## المعمارية المبدئية

- تطبيق Android Native خفيف.
- وحدة File Manager.
- Local Transfer Server لخدمة صفحة الآيفون داخل الشبكة المحلية.
- Remote Control Server للتحكم المحلي بالشاشة.
- Screen Capture باستخدام MediaProjection.
- Remote Input باستخدام AccessibilityService.
- Inbox موحد للملفات الواردة.
- Download Manager.
- APK Inspector / Installer.
- Settings للتخزين والشبكة ومجلدات الحفظ والتحكم عن بعد.

## مراحل التنفيذ

### المرحلة 1
هيكل Android الأساسي + واجهة رئيسية + مدير الملفات.

### المرحلة 2
خادم النقل المحلي + صفحة الآيفون + QR + رفع وتنزيل الملفات.

### المرحلة 3
إرسال الروابط + مركز التنزيلات.

### المرحلة 4
مركز APK وفحص التوافق والتثبيت.

### المرحلة 5
التحكم بالشاشة من الآيفون: عرض الشاشة + اللمس والسحب + أزرار النظام + الصوت + الكتابة + الحماية برمز جلسة.

### المرحلة 6
اختبارات فعلية على شاشة السيارة وتحسين الأداء والتوافق واستهلاك الذاكرة.
