# DarbakTools — دربك Tools

صندوق أدوات خاص لشاشة السيارة، مصمم للعمل بخفة واستقرار على Android 7.1 / API 25 وشاشة 1024×600 أفقية.

## النسخة الأولى المعتمدة

1. مدير ملفات: الذاكرة الداخلية / USB / SD مع نسخ ونقل وحذف وإعادة تسمية وبحث وفرز.
2. اتصال الآيفون عبر الشبكة المحلية: صفحة محلية + QR بدون الحاجة لتطبيق إضافي على الآيفون.
3. إرسال واستقبال الملفات بين الآيفون والشاشة.
4. إرسال الروابط من الآيفون إلى الشاشة وفتحها أو تنزيل الملفات المباشرة.
5. مركز تنزيلات مع اختيار مكان الحفظ ومتابعة التقدم وإعادة المحاولة.
6. مركز APK: عرض معلومات الحزمة والإصدار وفحص التوافق الأساسي ثم التثبيت بموافقة المستخدم.

## مبادئ المشروع

- Android 7.1 / minSdk 25.
- 1024×600 Landscape.
- العربية وRTL أولًا.
- Offline-first؛ نقل الملفات المحلي لا يعتمد على سحابة.
- لا Firebase ولا Google Services للوظائف الأساسية.
- واجهة خفيفة مناسبة لذاكرة محدودة.
- أزرار كبيرة مناسبة لشاشة السيارة.
- عدم تنفيذ عمليات حذف أو تثبيت حساسة دون تأكيد واضح.
- المشروع للاستخدام الخاص ويدعم تثبيت APK مباشرة خارج Google Play.

## المعمارية المبدئية

- تطبيق Android Native خفيف.
- وحدة File Manager.
- Local Transfer Server لخدمة صفحة الآيفون داخل الشبكة المحلية.
- Inbox موحد للملفات الواردة.
- Download Manager.
- APK Inspector / Installer.
- Settings للتخزين والشبكة ومجلدات الحفظ.

## مراحل التنفيذ

### المرحلة 1
هيكل Android الأساسي + واجهة رئيسية + مدير الملفات.

### المرحلة 2
خادم النقل المحلي + صفحة الآيفون + QR + رفع وتنزيل الملفات.

### المرحلة 3
إرسال الروابط + مركز التنزيلات.

### المرحلة 4
مركز APK وفحص التوافق والتثبيت.

### المرحلة 5
اختبارات فعلية على شاشة السيارة وتحسين الأداء والتوافق.
