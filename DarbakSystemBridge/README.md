# Darbak System Bridge

أداة تمهيدية آمنة لشاشات السيارة القديمة من نوع Allwinner T3.

## ما الذي تفعله النسخة 0.1.0؟

- تعرض إصدار Android الحقيقي وAPI وبصمة البناء والمعالج والذاكرة والتخزين.
- تفحص وجود `su` وصلاحية Root دون تعديل النظام.
- تحاول تشغيل ADB عبر Wi-Fi مؤقتًا على المنفذ `5555` عند توفر Root فقط.
- لا تضيف تشغيلًا تلقائيًا ولا تعدّل ملفات `/system` ولا تحفظ الإعداد بعد إعادة التشغيل.
- تتطلب ضغطًا مطولًا وتشديدًا ثانيًا قبل تشغيل أو إيقاف ADB.
- تحفظ تقريرًا نصيًا في `/DarbakSystem/DarbakSystem-report.txt`.

## التوافق

- الحد الأدنى Android 5.0 / API 21.
- مستهدف Android 7.1 / API 25.
- واجهة أفقية عربية خفيفة لشاشة 1024×600.

## البناء

```bash
gradle :app:assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
